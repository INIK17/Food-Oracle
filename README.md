# 🍔 Food Oracle

AI-Powered Food Delivery Time Prediction

## 🚀 Live Demo

[👉 Try Food Oracle Live](https://food-oracle-mrtxdrvj8m4tgfbutqowzj.streamlit.app)

## 🧠 Features

- Machine Learning based delivery time prediction
- Random Forest prediction model
- Considers traffic, distance, rider and restaurant details
- Interactive Streamlit interface

## 🛠️ Tech Stack

- **Python**
- **Machine Learning**
- **Streamlit**
- **Scikit-learn**
- **Pandas**
- **NumPy**
- **Joblib**

---

## 🧠 Machine Learning

Food Oracle uses a trained Machine Learning prediction model to estimate food delivery time.

The trained model is loaded by the Streamlit application and used to generate predictions based on the information entered by the user.

> The trained model file is not included in this repository because of its large file size.
